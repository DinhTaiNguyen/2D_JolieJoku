# Jolie Joku Adventure

A static 2D web game for Joku and Jolie, designed for smooth desktop and mobile play.

## Local run

Serve the folder with any static server:

```powershell
python -m http.server 5173
```

Then open `http://localhost:5173`.

## Deploy

Upload `index.html`, `src/`, and `assets/` to any static host such as Netlify, Vercel,
GitHub Pages, Cloudflare Pages, or an ordinary web server.
